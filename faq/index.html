Help Center

Frequently asked questions.

Use this page for store rules, checkout notes, delivery information, refund policies, and links to your Discord support channel.

Can this website process payments directly?

No. GitHub Pages is static hosting, so real payments should go through a hosted checkout provider such as Tebex, PayPal, Stripe Checkout, or another payment service.

How do I connect a package to Tebex?

Create the product in Tebex, copy its checkout or package URL, then paste that URL into the matching checkoutUrl field in content/packages.json.

Where do I change resource names and prices?

Open content/packages.json in this repo and edit the packages array. The store page automatically renders the cards from that data.

Can I add more pages?

Yes. Copy one of the existing HTML pages, update the page content, and add the new link to the navigation and footer on each page.

How do customers get support?

Replace the Discord placeholder links with your server invite or support ticket URL. You can also add rules, terms, or refund details directly on this page.
